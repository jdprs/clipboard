# 摘板 ClipBoard

一个临时的网页摘录对照工具。

平时从好几个网页里找信息、对比内容，得来回切标签页、复制粘贴，挺烦的。这个插件就是把每个页面里你真正关心的那几句话、那张图摘出来，放到一个悬浮在屏幕上的小面板里，对着看、对着抄。

它不是笔记软件，不存云端、不建知识库，关掉浏览器默认就没了，就是个临时草稿板。

## 能干什么

- 网页里选中文字，或者右键图片，选「加入摘板」，就进面板了。每条都记着是从哪个网页摘的，点一下能跳回去。
- 面板一直在屏幕上，切标签页也不消失。可以拖着走、拉大拉小，拖到屏幕边缘会缩成一条，点一下又展开。
- 可以建几个临时分组，比如「电脑参数对比」「酒店备选」，同一主题的东西放一起，用完一键清空。
- 每条可以标个「重点」「待确认」，卡片之间能拖来拖去排序。
- 数据只存在浏览器本地，不上传、不用登录。

## 怎么装

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选这个文件夹
4. 把「摘板」固定到工具栏，打开任意网页就能用

Chrome 自己的页面（`chrome://` 开头的、应用商店这些）不允许插件注入脚本，所以这些页面上不会出现面板，是浏览器的限制，普通网页都正常。

## 什么时候用得上

- 网购：把几个商品的价格、参数、售后摘出来并排看
- 写东西：从好几篇资料里摘素材，对着正文写，不用来回切
- 填表：把证件号、地址摘出来挂在旁边，对着填
- 做攻略：几个行程、酒店、票价放一起比

## 文件结构

```
clipboard-extension/
├── manifest.json
├── background.js      # 右键菜单、落库、图片转 base64、启动清理
├── content.js         # 悬浮面板（拖拽、缩放、分组、排序、标记）
├── popup/
│   ├── popup.html
│   └── popup.js
└── icons/
```

纯前端，没有后端，数据放在 `chrome.storage.local` 里。
